# Clearfield

浏览器扫雷。克隆后直接打开 `index.html`。

| 难度 | 棋盘 | 雷 |
| --- | --- | --- |
| 初级 | 9×9 | 10 |
| 中级 | 16×16 | 40 |
| 高级 | 30×16 | 99 |

左键翻开，右键插旗。第一下落子会空出周围一圈，并展开一块空地。已经翻开的数字保持不变。每次点击之后，还没翻开的雷会在仍然满足这些数字的前提下随机移动；如果没有符合条件的新分布，雷就不动。打开的数字上双击，或按中键，会按当前数字翻开周围。

触屏可以切换「翻开 / 插旗」，也可以长按插旗。方向键移动格子，空格翻开，`F` 插旗，`D` 对已打开的数字做一次周围翻开。初级、中级、高级的最快时间记在这台浏览器里。

逻辑测试：

```bash
node test/engine.test.js
```
